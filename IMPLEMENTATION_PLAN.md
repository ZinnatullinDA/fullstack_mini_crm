# План реализации мини-CRM

Источник требований: `Тестовое задание мини-CRM «Объекты и задачи».docx`.

1. Подготовить React SPA на Vite с TypeScript, Tailwind, shadcn/ui и React Router.
2. Настроить ESLint Flat Config, Husky, lint-staged и Commitlint; проверять каждый этап перед коммитом.
3. Организовать модули приложения, маршруты, Supabase client и общие UI-состояния.
4. Создать таблицы профилей, объектов, задач и истории; предусмотреть мягкое удаление объектов и задач.
5. Включить RLS: постановщик видит и управляет всеми объектами и задачами; исполнитель видит собственные задачи и связанные объекты. Роль нельзя менять самостоятельно.
6. В БД обеспечить пять переходов статусов, обязательный комментарий при возврате, атомарную историю и защиту от прямого обхода.
7. Реализовать вход по email/паролю, выход, восстановление сессии и закрытые маршруты. Открытая регистрация запрещена.
8. Сделать экраны входа, списка и карточки объектов, карточки задачи с историей, списка «Мои задачи».
9. Подключить операции к Supabase и обновление данных после изменений.
10. Проверить сценарии интерфейса и RLS с реальными пользовательскими контекстами; записать только фактически выполненные проверки.
11. Описать настройку, миграции, тестовых пользователей, запуск и ограничения.

## Внешние зависимости

- Нужны URL проекта и публичный anon key для запуска фронтенда.
- Нужен доступ к проекту через Supabase MCP или другой авторизованный способ для проверки существующей схемы, применения миграций и проверки политик.
- Для E2E тестов нужны тестовые учётные записи с ролями постановщика и двух исполнителей; пароли не сохраняются в Git.
